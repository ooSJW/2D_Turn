1. 시작하기 : 1_Scene폴더의 InitializeScene에서 시작합니다.

2. 영웅 장착하기 : LobbyScene에서 영웅 버튼 클릭 -> 장착 하려는 영웅 초상화 클릭 -> "팀 배치" 버튼 클릭 -> 좌측 슬롯 선택.

3. 스테이지 보상 : 스테이지 클리어 보상으로는 골드 및 아이템, 새로운 영웅이 해금됩니다.
	           보상 수령 후 로비로 돌아가 새로운 영웅, 아이템 장착을 통해 팀을 성장시킬 수 있습니다.

4. 스테이지 : 본 포트폴리오는 총 7개의 스테이지로 구성되어있습니다.
	    2스테이지는 로비의 모험 버튼 클릭 후 오른쪽으로 스크롤 하여 확인할 수 있습니다.

5. 아이템 장착 및 강화 : 보상으로 획득한 아이템은 Lobby에서 장착 및 강화를 진행할 수 있습니다.
		      영웅 버튼 클릭 -> 장착 시켜줄 영웅 초상화 클릭 -> 아이템 슬롯 클릭 -> 아이템 선택 -> 장착 혹은 강화 선택.

감사합니다.
